投票審査とは

　VIPRPG紅白2012では、公開された各作品を一般プレイヤーの投票によって評価し、その点数で順位を決定します。
　9つの部門ごとに投票が行われ部門別順位を決定し、各部門の合計点数により総合順位が決定されます。 　さらに紅組・白組ごとに点数を集計し、点数のより多かった組が優勝チームとなります。
　投票によって上位に選ばれた作品は専用ページに掲載されます。
　
　投票も祭りの楽しみのひとつです。参加者やプレイヤーの皆様の「このゲームはすごかった！」という思いを形にする試みです。
　難しく構えず、楽しんでいただければ幸いです。
　

  • 投票は誰でも自由に行えます。プレイヤー、作品投稿者の区別はありません。
  • 今年は投票数だけで競うのではなく、点数評価による審査を行います。
  • 投票者1人につき、すべての作品を審査できます。(1人1作品ではありません)
  • 投票者は、ひとつの作品ごとに1度しか審査できません。投票のやり直しはできません。
  • 遅刻提出された作品も審査対象になりますが、総合順位を決定する際に減点されます。
  • 投票の際に寄せられた「コメント」および「総評」は、結果発表時に一部抜粋またはすべて掲載する場合があります。
  • 結果発表で上位に選ばれた場合、後日管理側より作者様へメールを送信いたします。その際、差し支えなければ掲載用にコメントを頂ければ幸いです。（コメントは任意です）
  • 不正票・組織票は禁止です。

投票方法

投票所

　各作品ごとに専用の投票所が設置されています。投票所へは、各作品ページまたは作品一覧からリンクされています。
　　→　投票所一例

審査部門

　審査は9つ＋αの部門に分かれています。
　各10点満点で、最大90点＋その他加点で評価します。
　

熱中度

　その作品への熱中度を評価します。

技術

　技術面(テクニック)を評価します。

物語

　物語面(シナリオ)を評価します。

演出

　演出面(画像/音声/それらの使い方)を評価します。

斬新さ

　斬新さを評価します。

遊びやすさ

　遊びやすさ(インタフェース/プレイヤーへの配慮等)を評価します。

テラワロさ

　とにかく笑ったら点数オナシャス！

いやらしさ

　えっちだと思ったら点数をいれてください///

ひどさ

　特有の言葉にできない有り余るひどさを感じたら点数を投じましょう。

その他加点

　その作品の特によかったところを、複数選択方式で選んでください。
　総合順位を決定する際に加点されます。（部門別順位には加点されません）
　

アンケート

　審査結果発表時に、作品の紹介文として一緒に掲載します。
　お手隙であれば回答していただければ幸いです。（任意です）

コメント

作品に対する感想があれば一言お願いします。

総評

作品の紹介・レビューを一筆お願いします。

集計

　 　投票された点数の合計点だけではなく、平均点や中央値などを加味して得点を算出します。
　

部門別順位

　① … ( 小計順位点 + 平均順位点 ) × 重視補正(※)
　② … 中央値 × 2

　① + ② = 合計点

　(※ その作品の各部門ごとの小計のうち、
　 最も得点が高かった部門には 110% 乗算する。
　 補正している場合は合計点欄に ★ が記されている。)

総合順位

　９部門小計点 + ( その他加点 × 遅刻補正 )

　遅刻補正：　遅刻提出の場合、[ その他加点 ]を 2 で割る）

チーム勝敗

　総投票数、平均投票数、総得点、平均得点を、それぞれより多く獲得したほうを勝利チームとします。
