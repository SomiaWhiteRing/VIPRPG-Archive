投票について

　投票に関する詳細はこちらのページをご覧ください。
　　→　投票審査とは

部門別順位

　９＋１の各部門の得点順位です。

熱中度

　その作品への熱中度を評価します。
　　→　結果

技術

　技術面(テクニック)を評価します。
　　→　結果

物語

　物語面(シナリオ)を評価します。
　　→　結果

演出

　演出面(画像/音声/それらの使い方)を評価します。
　　→　結果

斬新さ

　斬新さを評価します。
　　→　結果

遊びやすさ

　遊びやすさ(インタフェース/プレイヤーへの配慮等)を評価します。
　　→　結果

テラワロさ

　とにかく笑ったら点数オナシャス！
　　→　結果

いやらしさ

　えっちだと思ったら点数が入ります///
　　→　結果

ひどさ

　特有の言葉にできない有り余るひどさを感じたら点数が投じられます。
　　→　結果

その他加点

　その作品の特によかったところを、複数選択方式で選びます。
　総合順位を決定する際に加点されます。（部門別順位には加点されません）
　　→　結果

総合順位

　すべての部門の結果を集計し、総合得点の順位です。

　　→　結果
　　→　結果(簡易版)

チーム勝敗

　紅組・白組どちらがより評価が高かったかを発表します。

　　→　結果

表彰会場

　各部門および総合順位において優れた評価を得た作品を紹介します。

　　→　結果
