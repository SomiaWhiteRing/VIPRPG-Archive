# 重启记录（2026-10-15）

持续校对的当前进度与顺序见 [逐祭典校对清单](restart-progress.md)。每校对完一个祭典即追加记录，直到覆盖全部祭典；下文保留各批次的历史证据。

## 本轮目标与边界

把遗留项目恢复到可以逐批推进的状态：清点真实缺口，修复桌面浏览基础，恢复有来源证据的内容，并留下可重复执行的入口。本轮不重新设计整个网站，不更换框架，不新增搜索／下载器等功能，不部署、不推送。用户已授权浏览器交互和人工 UI 检查，随后明确只考虑桌面。

## 已核实的旧状态

- 工作开始时 Git 工作树干净，HEAD 为 `1a0eff6`。
- 74 个祭典、4,090 条作品；2,319 条作品带 `detailDisabled: true`。另有一个祭典整体禁用详情，两者合计影响 2,356 条作品。
