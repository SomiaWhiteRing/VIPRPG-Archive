## 插入任务：已有受限条目补充归档（2026-10-17）

用户要求在 2012 突风祭完成后、开始 2011 电波游戏祭前，插入已有受限条目的补充归档任务，优先处理用户指出的 2012 夏之阵，再处理其他已归档祭典中的受限条目。此任务是既有祭典的修订，不增加 74 个祭典的总数，也不提前标记完成。

保存方式按用户最新要求调整：按已确认的来源直接保存数据，不主动审看条目内容或做关键词筛选；不再把含混标题、玩梗和不确定的图像作为新增受限依据。清点既有受限标记及被替换、删去的字段、缓存、资源和来源链接，纠正缺乏依据的受限处理，并按实际来源补档。旧缓存已中性化或原图已删除的，重新从源站或存档获取，不凭旧报告推测内容。

逐祭典同步整理版、原貌版和恢复脚本，核对结构、编码、本地资源、来源记录和桌面显示；修订验收后更新该祭典进度及证据，并各自提交。保留此前验收记录作为历史，另记本次修订结果；源站或存档暂不可达的具体缺口继续列出。完成这批修订后回到原顺序，从 2011 电波游戏祭继续。

## 本轮目标与边界

把遗留项目恢复到可以逐批推进的状态：清点真实缺口，修复桌面浏览基础，恢复有来源证据的内容，并留下可重复执行的入口。本轮不重新设计整个网站，不更换框架，不新增搜索／下载器等功能，不部署、不推送。用户已授权浏览器交互和人工 UI 检查，随后明确只考虑桌面。
